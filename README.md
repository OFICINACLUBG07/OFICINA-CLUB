# Oficina Club

Sistema web inicial para controle de clientes, veículos, peças, serviços e ordens de serviço.

## Recursos

- Painel com resumo das ordens
- Cadastro de clientes e veículos
- Cadastro de peças e serviços
- Controle simples de estoque
- Emissão e impressão de ordens de serviço
- Backup dos dados em JSON
- Interface responsiva para celular e computador

## Publicação no GitHub Pages

1. Abra **Settings** no repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

O endereço será `https://oficinaclubg07.github.io/OFICINA-CLUB/`.

## Importante

Esta primeira versão salva os registros no navegador do aparelho usando armazenamento local. Ela funciona para teste e uso em um único navegador. Para vários usuários e aparelhos compartilharem os mesmos dados, a próxima versão deve usar login, servidor e banco de dados online.
